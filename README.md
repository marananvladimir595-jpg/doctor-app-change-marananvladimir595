# Doctor Appointment App

Учебный проект: мобильное приложение для записи к врачу.

## Текущее состояние
- завершено 40% работ;
- использовано 45% бюджета;
- velocity: 18 SP за итерацию;
- осталось 54 SP в бэклоге;
- сейчас конец 3-й итерации из 6.

## Новое требование
Заказчик просит добавить видеоконсультации. Решение ещё не принято.

## Решение по видеоконсультациям

**Вопрос заказчику:** Видеозвонок должен быть встроен в приложение или достаточно перехода во внешний сервис? Нужны ли запись и оплата внутри приложения?

**Категория MoSCoW:** Should

**Влияние на сроки:** Требование не влезает в оставшиеся 3 итерации без компромисса. Вариант — взять в следующей итерации или сделать MVP.

**Влияние на бюджет:** Может потребовать дополнительных часов разработки и тестирования. Либо бюджет сохраняется за счёт переноса других задач.

**Решение:** Перенести на следующую итерацию / сделать MVP после уточнения объёма.

**Почему:** Текущий бэклог (54 SP) уже заполняет оставшиеся 3 итерации при скорости 18 SP/итерацию. Внедрение крупной функции без корректировки плана невозможно.
